# 통근 모드 MVP

`/#commute` 또는 첫 화면의 **통근 · 짧은 코드 풀기**에서 시작합니다. 자체 작성한 Python 함수 문제 10개를 1~3분 목표로 풀고, 힌트 하나씩 → 제출 → 입출력 확인표 → 선택한 경우 모범 풀이 → 자가 판단 → 작은 변형 순서로 진행합니다. 공개·유료 코딩테스트의 문제나 해설을 복제하지 않았습니다.

## 편집기

- `def solution(...):`, `if ...:` 등 블록 뒤 Enter는 공백 4개를 추가합니다. 보통 줄과 빈 줄은 기존 들여쓰기를 유지합니다.
- 문자열·주석 속 콜론은 블록 시작으로 취급하지 않습니다. 이 기능은 편집 보조이며 Python 구문 분석기는 아닙니다.
- 들여쓰기·내어쓰기, 괄호·대괄호·중괄호·따옴표 감싸기, 기호 입력, 실행 취소·다시 실행을 제공합니다.
- 선택한 여러 줄의 들여쓰기, 선택한 텍스트를 괄호로 감싸기, 커서 유지, 자동 들여쓰기 끄기를 지원합니다.
- 붙여넣은 코드를 자동 재포맷하지 않습니다. IME 조합 중 Enter와 도구 입력을 가로채지 않습니다.
- 도구 모음은 가로로 밀어서 사용합니다. 화면 회전·뷰포트 축소 때 편집기를 다시 만들지 않습니다.

## 채점의 한계

이 MVP에는 **Python 실행기가 없습니다**. `def solution`·`return` 같은 기본 형태만 참고용으로 점검하며, 문자열 일치율로 정답을 판정하지 않습니다. 다른 변수명·합법적인 다른 풀이는 허용됩니다. 입출력 확인표는 **기대값**이지 사용자 코드의 실행 결과가 아닙니다.

모든 시도에 `verified: false`를 저장합니다. 화면의 **독립 자가 확인**, **도움 후 자가 확인**, **다시 볼 것**은 본인의 판단이며 자동 실행 통과가 아닙니다. 자동 실행 통과·실패·시간 초과 같은 상태는 표시하지 않습니다. 외부 AI, Python 런타임 다운로드, 계정·키 설정은 추가하지 않았습니다. 향후 실행기를 넣을 때는 브라우저 격리와 강제 종료를 별도로 검증해야 합니다.

입출력 테스트 44개와 경계 오류 예시 10개로 검증한 것은 저장소가 작성한 **모범 풀이와 테스트 데이터**입니다. 사용자 답안을 호스트에서 실행하는 서버나 엔드포인트는 없습니다.

## 기록과 복습

기존 `algo-memory:v1` 및 기존 PC/계정 동기화는 유지합니다. 통근 데이터는 버전이 있는 별도 키 `algo-memory:commute:v1`에 저장하며, 기존 암기 점수·연속 기록에는 넣지 않습니다. 통근 기록은 계정으로 자동 동기화하지 않습니다.

- 힌트 수, 모범 풀이 열람, 소요 시간(문제를 연 뒤 제출까지의 실제 경과 시간), 자가 판단을 기록합니다.
- 힌트나 풀이를 본 날의 같은 문제 재시도는 독립 시도로 기록하지 않습니다.
- 독립 자가 통과 시 1·3·7·14·30일 간격으로 다음 복습을 예약합니다. 도움을 쓰거나 다시 볼 문제는 다음 날로 예약합니다.
- 3분 이내 독립 자가 통과 2회 연속이면 한 단계 올립니다(최대 L3). 다시 볼 문제는 한 단계 낮춥니다(최소 L1). 수동 난이도 선택도 가능합니다. 이는 실행 정답률을 추정하는 알고리즘이 아닙니다.
- 초안·선택 범위·힌트·제출 상태를 새로고침 후 복원합니다. 시도는 문제당 최근 80개, 실행 취소는 현재 편집 세션의 최근 100개입니다.
- 오늘 목록의 **저장과 백업**에서 통근 JSON을 복사하고 복원할 수 있습니다. 복원은 명시적 확인 후 통근 기록만 교체합니다. 기존 설정의 JSON 백업에는 `daily`와 `commute`도 추가했습니다.
- 손상되거나 지원하지 않는 버전의 저장 데이터는 덮어쓰지 않고 화면에서만 연습합니다. 원본 JSON 백업을 먼저 보관할 수 있습니다. 저장 실패는 화면에 표시합니다.

## 로컬 실행과 오프라인 범위

```powershell
npm ci
npm run serve
# http://127.0.0.1:8080/#commute
```

서버는 **127.0.0.1만** 사용하며 HTML과 기존 Neon 제공자 번들만 제공합니다. LAN 공개·답안 실행·소스 파일 제공은 하지 않습니다. 포트 8080이 사용 중이면 기존 프로세스를 임의 종료하지 말고 다른 환경에서 확인하세요.

개발 의존성 설치에는 네트워크가 필요합니다. 기존 PC 모드의 선택적 계정 기능은 기존 Neon/Supabase 설정 및 네트워크를 사용하고, Google Fonts도 기존 외부 의존성입니다. 통근 문제·편집기·자가 확인에는 새 네트워크 의존성이 없습니다. 이미 내려받은 `dist/algo-memory.html#commute`의 핵심 흐름은 Chrome 오프라인 모드에서 확인했으며, 글꼴은 시스템 폰트로 대체됩니다. PC 계정 기능을 포함한 로컬 제공에는 같은 `dist/`의 `neon-provider.js`도 유지하세요. 웹사이트의 오프라인 재방문을 위한 서비스 워커/PWA 설치 기능은 없습니다.

## 검증 재현

```powershell
npm run lint
npm test
npm run test:commute-catalog
npm run test:browser
```

브라우저 검사는 설치된 Chrome/Edge를 사용하며 다운로드하지 않습니다. 필요하면 `BROWSER_PATH`로 실행 파일을 지정합니다. 서버는 루프백에만 바인딩하고 외부 요청은 차단하며, 검사 종료 때 닫습니다. 기존 계정 제공자는 기존 롤백 플래그와 SDK 요청 차단으로 실행하지 않습니다. 실제 클라우드 계정 동기화는 이 검사 범위 밖입니다. `qa-local/`의 스크린샷은 Git에서 제외합니다. `QA_DIR`로 증거 저장 위치를 지정할 수 있습니다.
