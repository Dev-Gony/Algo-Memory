# 통근 모드

현재는 실제 Python 입력·출력 채점과 격리 Worker 종료를 지원합니다. **실행기 구조·오류 구분·초기 12.3MB 로딩·오프라인 한계·v1/v2 데이터 호환은 [python-execution.md](python-execution.md)를 확인하세요.**

## 편집기

- `def solution(...):`, `if ...:` 등 블록 뒤 Enter는 공백 4개를 추가합니다. 보통 줄과 빈 줄은 기존 들여쓰기를 유지합니다.
- 문자열·주석 속 콜론은 블록 시작으로 취급하지 않습니다. 이 기능은 편집 보조이며 Python 구문 분석기는 아닙니다.
- 들여쓰기·내어쓰기, 괄호·대괄호·중괄호·따옴표 감싸기, 기호 입력, 실행 취소·다시 실행을 제공합니다.
- 선택한 여러 줄의 들여쓰기, 선택한 텍스트를 괄호로 감싸기, 커서 유지, 자동 들여쓰기 끄기를 지원합니다.
- 붙여넣은 코드를 자동 재포맷하지 않습니다. IME 조합 중 Enter와 도구 입력을 가로채지 않습니다.
- 도구 모음은 가로로 밀어서 사용합니다. 화면 회전·뷰포트 축소 때 편집기를 다시 만들지 않습니다.

## 실행과 검증

```powershell
npm ci
npm run serve
# http://127.0.0.1:8080/#commute
npm test
npm run lint
npm run test:commute-catalog
npm run test:browser
npm run test:python-browser
```

기존 PC 모드와 기록을 유지하며 통근 화면에서 자체 Python 함수 문제 10개를 연습합니다. 실행 채점은 기본 버튼으로, 미검증 자가 확인은 별도 버튼으로 제공합니다. 서버는 127.0.0.1에만 바인딩합니다.
