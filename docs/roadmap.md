# 로드맵

## 지금까지 (v1.0)

깜지(트레이싱) → 실전(백지) 루프, 실패 시 깜지 횟수 승급, 망각곡선 스케줄러,
난이도 6단계 템플릿 70개, 암기 판정, 관문 모드, 일일 필사량, 독서 기록, 통계.

## 다음 후보

각각 기능 브랜치가 하나씩 열려 있다. 우선순위는 실제로 써 보고 정한다.

### 1. 실행 채점 — `feat/code-execution`
지금은 "구조를 재현했는가"까지만 판정한다. 실제로 돌아가는지는 모른다.
통암기 목적에는 충분하지만, 실전 감각을 위해서는 실행 결과 비교가 필요하다.

### 2. 모바일 입력 — `fix/mobile-ime`
깜지는 키보드를 한 글자씩 받는 구조라 모바일 IME에서 검증이 덜 됐다.
데스크톱 한글 조합은 처리했지만 안드로이드/iOS 키보드는 동작이 다르다.

### 3. 템플릿 확장 — `content/expand-catalog`
70개로는 중급·고급 구간 커버리지가 얇다. 100~120개를 목표로 한다.

### 4. 승급 폭 조정 (실사용 후 결정)
지금은 실패할 때마다 깜지 +1회, 상한 10회. 4~5회부터 지겨워서
앱을 안 켜게 되는지, 아니면 화가 나서 외워지는지는 데이터가 필요하다.
포기 버튼 누적 횟수와 재방문율을 보고 정한다.

### 5. 알림 (네이티브 영역)
"코드를 못 쓰면 안 꺼지는 알람"은 OS 알림 권한이 필요해 웹으로는 한계가 있다.
관문 모드가 웹에서 할 수 있는 최선이다. PWA 알림까지가 현실적인 선.
