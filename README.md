# Algo-Memory

에빙하우스 망각곡선 기반 **알고리즘 통암기 스케줄러**.
코딩테스트 대표 유형의 코드를 통째로 외우고, 정말 외웠는지를 백지 재현으로 검증한다.

> 백준(BOJ) 같은 온라인 저지는 "맞았습니다"까지만 알려줬다.
> 그 코드를 한 달 뒤에도 기억하는지는 아무도 관리해주지 않았다. 그 구멍을 메우는 도구다.

## 핵심 루프

```
깜지 1회  →  실전  →  실패  →
깜지 2회  →  실전  →  실패  →
깜지 3회  →  실전  →  통과  →  깜지 1회로 리셋
```

* **깜지** — 연습지 위에 코드가 회색으로 깔려 있고 그 위를 그대로 따라 친다.
  틀린 글자는 입력 자체가 막히고, 들여쓰기는 자동으로 넘어간다. 트레이싱지에 대고 그리는 것과 같다.
* **실전** — 완전한 백지. 힌트 없음, 시간 제한 있음.
* **승급** — 실전에서 막히거나 `모르겠다`를 누를 때마다 다음 깜지 횟수가 1회씩 늘어난다.

## 암기 판정

아래 **셋을 모두** 만족한 회차만 "완벽 재현" 1회로 친다. 하나라도 어긋나면 연속 기록은 0으로 돌아간다.

| 조건 | 기준 |
| --- | --- |
| 일치율 | 100% (공백·주석은 무시하고 구조만 대조) |
| 핵심 구조 | 누락 0개 (def/for/while/if/return/deque/heapq/dp 등 자동 추출) |
| 제한 시간 | 원본 줄 수 × 10초 + 30초 (설정 변경 가능) |

**연속 3회** 완벽하면 `암기 완료`. 30일이 지나면 자동으로 `재확인 필요`로 내려온다.

## 난이도 6단계 · 내장 템플릿 70개

| 단계 | 개수 | 내용 |
| --- | --- | --- |
| 첫걸음 | 12 | 변수·연산·함수·if·for·while·리스트·문자열·딕셔너리·입력 |
| 입문 | 7 | 컴프리헨션, enumerate·zip, 2차원 배열, 정렬 기본 |
| 초보 | 12 | 해시, 누적합, 그리디, 슬라이딩 윈도우, 약수·소수, 빠른 입력 |
| 중급 | 18 | BFS·DFS, 스택, 조합·순열 재귀, 기본 DP, 이분탐색, 투포인터 |
| 고급 | 16 | 다익스트라, 플로이드, 위상정렬, MST, LIS, LCS, KMP, 비트마스크 DP |
| 코테 실전 | 5 | 빠른 입출력, 상태 추가 BFS, 경로 복원, 좌표 압축, 방향 시뮬레이션 |

**70개 전부 실제로 실행해서 검증한 코드다.** 틀린 코드를 다섯 번 반복 암기하면 최악이므로
`content/` 의 파이썬 소스에 각 템플릿마다 단위 테스트가 붙어 있고, CI에서 매번 돌린다.
코드는 전부 ASCII다 — 깜지 도중 한/영 전환을 강요하지 않기 위해서다.

## 그 외

* **망각곡선 스케줄러** — 학습일 기준 1·3·7·14·30일 복습 자동 생성
* **코스** — 난이도별 일차 계획, 하루 N개 페이스로 배치
* **관문 모드** — 오늘 것을 통과하기 전에는 다른 화면이 열리지 않는다 (회피 횟수는 통계에 남는다)
* **일일 필사량** — 00시 기준으로 쓴 줄 / 정확했던 줄, 연속 기록 일수
* **독서·인사이트** — 진도율과 핵심 문장 누적
* **통계** — 달성률, 통과율, 누락, 자주 틀리는 코드 블록 패턴, 난이도별 암기 진척

## 개발

```bash
npm install
npm run build     # src/ → dist/algo-memory.html (단일 파일)
npm test          # 빌드 + jsdom 종단 테스트
npm run serve     # http://localhost:8080
npm run catalog   # 템플릿 70개 재검증 후 catalog.json 재생성
```

### 구조

```
src/index.html      셸 (빌드 시 CSS/JS가 인라인으로 주입된다)
src/styles.css      디자인 토큰 + 전체 스타일
src/app.js          앱 전체 (상태·저장·채점 엔진·뷰)
src/catalog.json    문제 템플릿 70개 (content/ 에서 생성)
content/catalog*.py 템플릿 원본 + 실행 검증 테스트
test/               jsdom 종단 테스트 + 가짜 계정 저장소
dist/               배포 산출물 (단일 HTML)
```

배포 대상은 항상 `dist/algo-memory.html` 하나다. 외부 요청은 구글 폰트뿐이고
나머지는 전부 파일 안에 들어 있다.
